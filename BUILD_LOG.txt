SECTION 3: FILE CREATION ORDER & PURPOSE
--------------------------------------------------------

[1]  CMakeLists.txt
     Purpose : CMake build definition
     Key content:
       - cmake_minimum_required(VERSION 3.22)
       - project(ComplexityAnalyzer VERSION 1.0 LANGUAGES CXX)
       - set(CMAKE_CXX_STANDARD 17)
       - set(CMAKE_AUTOMOC ON)  [for Qt MOC code generation]
       - find_package(Qt6 REQUIRED COMPONENTS Widgets Charts)
       - add_executable(ComplexityAnalyzer main.cpp ...)
       - target_link_libraries(... Qt6::Widgets Qt6::Charts)

[2]  src\ASTNode.h
     Purpose : Data structure for the Abstract Syntax Tree
     Key content:
       - struct ASTNode { label, depth, lineNumber, children }
       - children is std::vector<std::shared_ptr<ASTNode>>

[3]  src\TokenProcessor.h
     Purpose : Token type definitions and tokenizer interface
     Key content:
       - enum class TokenType { FOR, WHILE, DO, SORT,
           BINARY_SEARCH, QUEUE_OP, STACK_OP, PRIORITY_QUEUE,
           HASH_MAP, MAP_OP, MEMO_MAP, BIT_OP, FUNC_DEF, ... }
       - struct Token { type, text, lineNumber }
       - class TokenProcessor { tokenize(), functionNames }

[4]  src\TokenProcessor.cpp
     Purpose : Tokenizer implementation
     Key content:
       - Strips // and /* */ comments
       - Emits brace/paren tokens character-by-character
       - Classifies words: for/while/sort/binary_search/
         queue/stack/priority_queue/unordered_map/dp[]/bit-ops
       - Collects function names (for recursion detection)

[5]  src\LoopDetector.h
     Purpose : Loop nesting depth tracker interface
     Key content:
       - struct LoopInfo { maxDepth, forLoops, whileLoops,
           hasSort, hasBinSearch, hasMapOp }

[6]  src\LoopDetector.cpp
     Purpose : Loop depth detection using std::stack
     Key content:
       - std::stack<bool> loopBraces
       - Push true on OPEN_BRACE after FOR/WHILE/DO token
       - Pop on CLOSE_BRACE, decrement depth if loop brace
       - Track maxDepth reached during scan

[7]  src\ASTBuilder.h
     Purpose : AST builder interface

[8]  src\ASTBuilder.cpp
     Purpose : Builds tree from token stream
     Key content:
       - std::stack<shared_ptr<ASTNode>> parentStack
       - Push new node on OPEN_BRACE after FOR/WHILE/IF/ELSE
       - Pop on CLOSE_BRACE
       - Leaf nodes for SORT, BINARY_SEARCH, QUEUE_OP,
         PRIORITY_QUEUE, MEMO_MAP, SWAP_OP, BIT_OP, FUNC_DEF

[9]  src\PatternTracker.h
     Purpose : Pattern counting + AlgorithmKind enum
     Key content:
       - enum class AlgorithmKind { BUBBLE_SORT, BFS,
           DFS_RECURSIVE, MEMOIZATION, TABULATION,
           GREEDY_HEAP, BINARY_SEARCH, HASHING,
           BIT_MANIPULATION, BACKTRACKING, ... }
       - algorithmName(), algorithmComplexity(),
         algorithmBetterAlternative() functions declared
       - struct PatternCounts { unordered_map<string,int> counts,
           bool hasSort/hasBinSearch/hasQueue/hasMemo/... }

[10] src\PatternTracker.cpp
     Purpose : Pattern tracking + algorithm lookup tables
     Key content:
       - algorithmName()        — human readable names
       - algorithmComplexity()  — "O(n²) avg, O(n²) worst" etc.
       - algorithmBetterAlternative() — specific advice per algo
       - PatternTracker::track() — fills PatternCounts from tokens

[11] src\ComplexityEstimator.h
     Purpose : Complexity estimate result types
     Key content:
       - enum class ComplexityClass { O1, OLogN, ON, ONLogN,
           ON2, ON2LogN, ON3, ONK }
       - struct ComplexityResult { label, cls, depth }

[12] src\ComplexityEstimator.cpp
     Purpose : Big-O rule engine
     Key content:
       - depth=0, no sort → O(1)
       - depth=0, hasSort → O(n log n)
       - depth=1, no sort → O(n)
       - depth=1, sort    → O(n log n)
       - depth=2, no sort → O(n²)
       - depth=2, sort    → O(n² log n)
       - depth=3          → O(n³)
       - depth>3          → O(n^k)

[13] src\SuggestionEngine.h
     Purpose : Suggestion type and interface
     Key content:
       - struct Suggestion { severity(1-5), icon, text }
       - max-heap ordering via operator<
       - forward declaration of AnalysisResult

[14] src\SuggestionEngine.cpp
     Purpose : Ranked suggestions using std::priority_queue
     Key content:
       - Section 1: Algorithm-specific better alternative tip
       - Section 2: Nesting/complexity warnings
           (triple loop, sort-inside-loop, O(n²) alternatives)
       - Section 3: Pattern-specific tips
           (linear→binary search, BFS→Dijkstra, DFS stack overflow,
            DP memo warning, two-pointer hint, sliding window hint,
            hash map reserve, backtracking pruning)

[15] src\Analyzer.h
     Purpose : Facade interface + AnalysisResult struct
     Key content:
       - struct AnalysisResult { complexity, complexityClass,
           maxDepth, hasSort/hasQueue/hasMemo/...,
           forLoops, whileLoops, primaryAlgorithm,
           secondaryAlgorithm, patterns, ast, suggestions }
       - class Analyzer { analyze(), identifyPrimary(),
           identifySecondary() }

[16] src\Analyzer.cpp
     Purpose : Main analysis pipeline + algorithm ID logic
     Key content:
       - Calls TokenProcessor → LoopDetector → ASTBuilder
         → PatternTracker → ComplexityEstimator → SuggestionEngine
       - identifyPrimary(): heuristic rules per AlgorithmKind
           queue+loop→BFS, 2loops+swap→BubbleSort,
           recursion+swap→QuickSort, dp[]+loop→Tabulation, etc.
       - identifySecondary(): checks remaining flags

[17] gui\SyntaxHighlighter.h / .cpp
     Purpose : VS Code-style C++ syntax highlighting
     Key content:
       - Extends QSyntaxHighlighter
       - Rules: C++ keywords (blue), STL types (teal),
         DSA functions (yellow), numbers (green),
         strings (orange), preprocessor (grey), comments (green)
       - Handles multi-line /* */ block comments

[18] gui\ChartHelper.h / .cpp
     Purpose : Complexity growth chart with 7 curves
     Key content:
       - Creates QChart with 7 QLineSeries:
         O(1), O(log n), O(n), O(n log n), O(n²), O(n² log n), O(n³)
       - Highlighted curve is bright + thick (width=4)

       - Manual axis setup (addAxis) — avoids null QGraphicsScene crash
       - Dark background (#1e1e2e), styled axes
